# uninter-ads-college-works

Este repositório contém os trabalhos e projetos desenvolvidos durante o curso de Análise e Desenvolvimento de Sistemas na UNINTER. Cada pasta neste repositório representa um trabalho ou atividade acadêmica, cobrindo diferentes áreas do curso, como programação, banco de dados, engenharia de software, entre outros.

## Tecnologias Utilizadas

- Python
- Java
- SQL
- HTML/CSS
- JavaScript
- Outros

## Projetos por Matéria

-   **/banco-de-dados-relacional**: Atividade da matéria de **Banco de Dados Relacional**, contendo o diagrama e os scripts SQL para criação e população de um banco de dados de uma livraria.
-   **/banco-de-dados-nosql**: Atividade da matéria de **Banco de Dados NoSQL**, utilizando Neo4j (Cypher) para modelar e consultar dados de tweets.
-   **/estrutura-de-dados**: Atividades da matéria de **Estrutura de Dados**, com implementações de uma fila de atendimento hospitalar e uma tabela hash.
-   **/big-data**: Projeto da matéria de **Big Data**, utilizando PySpark para análise de um conjunto de dados de reviews de filmes.
